Define a class with properties & a method

  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

    return `Hi, I'm ${this.name}`;
  }

class Person {
    String name;
    int age;
    Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
    String greet() {
        return "Hi, I'm " + name;

  def initialize(name, age)
    @name = name
    @age = age
  end
  def greet
    "Hi, I'm #{@name}"
  end
end

HTML Reference

Semantic elements, forms, media, and meta tags worth having on hand.

Document Structure
Boilerplate skeleton 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Page</title>
</head>
<body>
</body>
</html>
Character encoding & viewport meta 
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">

The viewport tag is required for responsive layouts to work at all on mobile — without it, the page renders zoomed out at desktop width.
SEO / social preview meta tags 
<meta name="description" content="Page summary">
<meta property="og:title" content="Page title">
<meta property="og:image" content="/preview.png">

og:* (Open Graph) tags control how the page renders when shared on social platforms and in chat apps.
Link an external stylesheet / favicon 
<link rel="stylesheet" href="/styles.css">
<link rel="icon" href="/favicon.ico">

Goes in <head>, unlike <script> which is usually placed at the end of <body> (or uses defer).
Preload / preconnect hints 
<link rel="preconnect" href="https://fonts.gstatic.com">
<link rel="preload" href="/hero.webp" as="image">

Hints the browser to fetch a critical resource earlier than it otherwise would — overusing them competes for the same bandwidth and can slow things down instead.
Canonical URL 
<link rel="canonical" href="https://example.com/page">

Tells search engines which URL is the "real" one when the same content is reachable through multiple URLs (tracking params, http/https, trailing slash).
Inline stylesheet 
<style>
  body { margin: 0; }
</style>

Valid in <head> or <body>, but conventionally kept in <head> alongside linked stylesheets.
Inline / external script, load timing 
<script src="/app.js" defer></script>
<script>
  console.log('inline');
</script>

defer runs the script after parsing finishes, in document order — usually what you want for a page script placed in <head>. async runs it as soon as it's loaded, in whatever order that happens, which is fine for independent scripts (analytics) but not for ones with dependencies between them.

Selectors
Descendant / direct child

.card > p

The first matches any p nested anywhere inside .card; the > form matches only a direct child.

Adjacent / general sibling 
h2 + p
h2 ~ p

+ matches the single element immediately following; ~ matches all later siblings.
Attribute selector

^= starts-with, $= ends-with, *= contains.
nth-child / nth-of-type 
li:nth-child(2n)
li:nth-child(2n+1)

2n selects even items, 2n+1 odd. nth-of-type counts only siblings of the same tag, ignoring other element types in between.
first/last-child, only-child 
li:first-child
li:last-child
li:only-child
:not() / :is() / :where()

:where() behaves like :is() but always has zero specificity, so it's easy to override.
has() — parent/relational selector

Selects a .card only if it contains an img — the closest thing CSS has to a "parent selector".
Box Model & Sizing
box-sizing 
box-sizing: border-box;

Width/height include padding and border, so the element doesn't grow past its declared size. Usually set once on *.
Shorthand order: margin/padding 
margin: 10px 20px 10px 20px;

Clockwise from top: top, right, bottom, left. Two values set vertical/horizontal; one value sets all four.
Viewport-relative units 
width: 100vw;
height: 100vh;
font-size: 4vmin;

vh/vw can misbehave on mobile with dynamic browser chrome — dvh/svh/lvh are the newer, more predictable alternatives.

clamp() for responsive values 
font-size: clamp(1rem, 2vw + 0.5rem, 2rem);

Arguments are min, preferred, max — avoids a pile of media-query breakpoints for simple fluid scaling.
Fit an image/video within its box 
img {
  width: 100%;
  height: 200px;
  object-fit: cover;
  object-position: center;
}

cover fills the box and crops overflow (most common for thumbnails); contain fits the whole image inside without cropping, leaving letterbox space; fill (the default) stretches and distorts the aspect ratio. object-position controls which part of the image stays visible when cropped.

Flexbox
Center content both axes 
display: flex;
align-items: center;
justify-content: center;
Main axis vs cross axis 
justify-content: space-between;
align-items: stretch;

justify-content works along the main axis (row by default); align-items works along the cross axis. Swap roles when flex-direction: column.

justify-content values:

flex-start
Packs items at the start of the main axis.
center
Packs items together in the middle.
flex-end
Packs items at the end of the main axis.
space-between
Spreads items out with the first and last flush against the edges.
space-around
Gives each item equal space on both sides, so gaps at the edges end up half the size of the gaps between items.
space-evenly
Makes every gap — including the edges — equal.

align-items values:

stretch (default)
Fills the cross-axis size of the container.
flex-start / center / flex-end
Packs items to the start, middle, or end of the cross axis without stretching them.
baseline
Aligns items by their text baseline — useful when they have different font sizes.

The unprefixed start/end are newer logical-direction equivalents of flex-start/flex-end that follow the container's writing mode instead of always meaning left-to-right/top-to-bottom.
Allow/prevent wrapping 
flex-wrap: wrap;
Child sizing: grow, shrink, basis 
flex: 1 1 200px;

Shorthand for flex-grow flex-shrink flex-basis. flex: 1 is common shorthand for "grow to fill available space".
Grid

Responsive auto-fit grid

Columns wrap automatically as space allows — no media query needed. auto-fill instead of auto-fit keeps empty tracks rather than stretching existing items.

z-index stacking 
z-index: 10;

Only applies to positioned elements (anything but static). A new stacking context (e.g. from transform or opacity < 1) can trap z-index values inside it regardless of how high they are.
Typography & Text
Truncate with ellipsis (single line) 
white-space: nowrap;
overflow: hidden;
text-overflow: ellipsis;

All three are required together.
Truncate with ellipsis (multi-line) 
display: -webkit-box;
-webkit-line-clamp: 3;
-webkit-box-orient: vertical;
overflow: hidden;

Widely supported despite the -webkit- prefix, but still worth a fallback max-height for the rare unsupported target.
Prevent long words from overflowing 
overflow-wrap: break-word;
Colors & Custom Properties
Define & use a CSS variable 
:root {
  --accent: #b3541e;
}
.btn {
  color: var(--accent);
}
Variable with a fallback 
color: var(--accent, #333);

Fallback is used only when --accent is unset, not when it's invalid.
Transparency via alpha channel 
background: rgb(0 0 0 / 50%);
background: #00000080;
Color function formats 
color: hsl(24 71% 39%);
color: oklch(55% 0.14 45);

hsl() is easy to reason about for tweaking lightness/saturation by hand. oklch() is perceptually uniform — bumping its lightness value changes perceived brightness consistently across hues, which hsl() doesn't guarantee.

Mix two colors 
background: color-mix(in srgb, var(--accent) 70%, white);

Handy for deriving a hover/tint shade from one base color instead of hand-picking a second hex value.
currentColor 
border: 1px solid currentColor;

Resolves to the element's own color value — useful so an icon's stroke or a border automatically tracks text color without a second variable.
Linear / radial gradient 
background: linear-gradient(to right, var(--accent), #f3e4d7);
background: radial-gradient(circle, #fff, var(--accent));
Force accessible color contrast 
color: light-dark(#24231f, #f7f7f5);

Picks the first value in light mode and the second in dark mode, based on the element's color-scheme — a lighter-weight alternative to duplicating rules inside a prefers-color-scheme media query.
Transitions & Animation
Basic transition 
transition: transform 0.2s ease-in-out;

Prefer animating transform/opacity over layout properties like width/top — they don't trigger reflow.
Keyframe animation 
@keyframes fade-in {
  from { opacity: 0; }
  to { opacity: 1; }
}
.el {
  animation: fade-in 0.3s ease-out;
}
Media & Container Queries
Responsive breakpoint 
@media (max-width: 600px) {
  .sidebar { display: none; }
}
@media (min-width: 900px) {
  .sidebar { display: block; }
}

max-width targets screens at or below the breakpoint (mobile-first overrides going down); min-width targets screens at or above it (the more common mobile-first base-up approach).
Container query 
.wrap { container-type: inline-size; }
@container (min-width: 400px) {
  .card { flex-direction: row; }
}

Reacts to the size of a containing element rather than the viewport — useful for components reused at different widths.
prefers-color-scheme 
@media (prefers-color-scheme: dark) {
  :root { --bg: #111; }
}
@media (prefers-color-scheme: light) {
  :root { --bg: #fff; }
}

Uses the system's prefered color scheme: dark or light.

Shell Commands

Everyday POSIX/bash one-liners for files, text, and processes.

Files & Directories
Find files by name 
find . -name "*.log"
Find and delete matching files 
find . -name "*.tmp" -delete

Or -exec rm {} \; on systems without GNU find's -delete.
Find files modified in last N days 
find . -mtime -7 -type f

Negative -7 means "less than 7 days ago"; plain 7 means "exactly 7".
Disk usage of a directory 
du -sh ./some-dir
Free disk space 
df -h
Copy/move recursively, preserving structure 
cp -r src/ dest/
rsync -av src/ dest/

rsync is safer for large/ongoing syncs — it resumes and only copies changed files.
Text & Search
Search recursively for a pattern 
grep -rn "TODO" ./src

-n shows line numbers, -r recurses into directories.
Search with extended regex, case-insensitive 
grep -Eri "error|warn" ./logs
Print a specific column of each line 
awk '{print $2}' file.txt

Fields split on whitespace by default; set -F, for CSV-style delimiters.
Replace text in-place across files 
sed -i '' 's/foo/bar/g' file.txt

The '' after -i is required on macOS/BSD sed for in-place edits with no backup suffix; GNU sed (Linux) omits it.
First/last N lines of a file 
head -n 20 file.txt
tail -n 20 file.txt
Follow a growing file (logs) 
tail -f app.log
Sort and remove duplicate lines 
sort file.txt | uniq

uniq only collapses adjacent duplicates, so the input must be sorted first.
Count lines/words/bytes 
wc -l file.txt
Processes & Jobs
Find a process by name 
ps aux | grep node

pgrep -a node does the same without the grep-matches-itself noise.
Kill a process by PID or name 
kill -9 <pid>
pkill -f node

-9 (SIGKILL) can't be caught/ignored — try a plain kill (SIGTERM) first so the process can clean up.
What's listening on a port 
lsof -i :3000
Run in background / detach 
long-task &
nohup long-task & disown

nohup + disown lets the process survive the shell session ending, not just backgrounding within it.
Permissions & Environment
Change file permissions 
chmod +x script.sh
chmod 644 file.txt
Change owner/group 
chown user:group file.txt
Set/read an environment variable 
export API_KEY="secret"
echo "$API_KEY"
Persist a variable across new shells 
echo 'export API_KEY="secret"' >> ~/.zshrc

Use ~/.bashrc/~/.bash_profile instead if the shell is bash.
Redirection & Pipes
Redirect stdout / append / stderr 
cmd > out.txt
cmd >> out.txt
cmd 2> err.txt
Redirect both stdout and stderr together 
cmd > all.txt 2>&1

Order matters — 2>&1 must come after the stdout redirect to point stderr at the same already-redirected target.
Chain commands: pipe, and, or 
cmd1 | cmd2
cmd1 && cmd2
cmd1 || cmd2

&& runs the next command only on success (exit code 0); || only on failure.

Substitute a command's output inline 
echo "Today is $(date)"
SSH
Connect to a remote host 
ssh user@host

Add -p 2222 if the server listens on a non-default port.
Connect using a specific private key 
ssh -i ~/.ssh/id_ed25519 user@host
Generate a new key pair 
ssh-keygen -t ed25519 -C "you@example.com"

Prefer ed25519 over the older rsa type — smaller keys, same or better security.
Copy a public key to a remote host's authorized_keys 
ssh-copy-id user@host

Without it, append manually: cat ~/.ssh/id_ed25519.pub | ssh user@host "cat >> ~/.ssh/authorized_keys"

Run a single remote command and exit 
ssh user@host "df -h && uptime"
Copy files to/from a remote host 
scp local-file.txt user@host:/remote/path/
scp user@host:/remote/path/file.txt ./

Add -r to copy directories recursively. rsync -av -e ssh is usually a better choice for large or repeated transfers.
Mount a remote directory over SSH 
sshfs user@host:/remote/path ./local-mount

Requires sshfs installed (e.g. via macFUSE on macOS). Unmount with umount ./local-mount.

Local port forwarding (tunnel a remote service) 
ssh -L 8080:localhost:80 user@host

Makes the remote host's port 80 reachable at localhost:8080 on your machine — handy for reaching a service (e.g. a database or admin panel) that isn't exposed publicly.
Keep a session open in the background 
ssh -f -N -L 8080:localhost:80 user@host

-N means "no remote command", -f backgrounds the process after authentication — useful for a long-lived tunnel.
Configure a host alias 
cat >> ~/.ssh/config <<'EOF'
Host myserver
  HostName 203.0.113.10
  User deploy
  IdentityFile ~/.ssh/id_ed25519
EOF

Afterward, just ssh myserver picks up the host, user, and key automatically.

SQL

Core ANSI SQL — mostly consistent across Postgres, MySQL, and SQLite. Edge cases noted where dialects diverge.

Querying
Select specific columns with a filter 
SELECT id, name FROM users WHERE age > 18;
Sort and limit results 
SELECT * FROM users
ORDER BY created_at DESC
LIMIT 10;

SQL Server uses TOP 10 instead of LIMIT.
Skip rows (pagination) 
SELECT * FROM users
ORDER BY id
LIMIT 10 OFFSET 20;
Distinct values 
SELECT DISTINCT country FROM users;
Pattern match / wildcard search 
SELECT * FROM users WHERE email LIKE '%@gmail.com';

% matches any run of characters, _ matches exactly one. Use ILIKE in Postgres for case-insensitive matching.
Match against a list of values 
SELECT * FROM users WHERE status IN ('active', 'trial');
Check for NULL 
SELECT * FROM users WHERE deleted_at IS NULL;

= NULL never matches anything — NULL comparisons always require IS [NOT] NULL.

Joins
Inner join 
SELECT o.id, u.name
FROM orders o
JOIN users u ON u.id = o.user_id;

Only returns rows with a match on both sides.
Left join 
SELECT u.name, o.id
FROM users u
LEFT JOIN orders o ON o.user_id = u.id;

Keeps every row from users even when there's no matching order — unmatched columns come back NULL.
Find rows with no match (anti-join) 
SELECT u.*
FROM users u
LEFT JOIN orders o ON o.user_id = u.id
WHERE o.id IS NULL;
Aggregation
Group with an aggregate function 
SELECT user_id, COUNT(*) AS order_count
FROM orders
GROUP BY user_id;
Filter groups after aggregation 
SELECT user_id, COUNT(*) AS order_count
FROM orders
GROUP BY user_id
HAVING COUNT(*) > 5;

WHERE filters rows before grouping; HAVING filters groups after aggregation — an aggregate like COUNT(*) can't be used in WHERE.

Common aggregate functions 
SELECT COUNT(*), SUM(amount), AVG(amount), MIN(amount), MAX(amount)
FROM orders;
Modifying Data
Insert a row 
INSERT INTO users (name, email) VALUES ('Ada', 'ada@example.com');
Insert and return the new row 
INSERT INTO users (name) VALUES ('Ada') RETURNING id;

Postgres/SQLite support RETURNING; MySQL doesn't — use LAST_INSERT_ID() instead.

Update matching rows 
UPDATE users SET status = 'active' WHERE id = 42;

Always pair UPDATE/DELETE with a WHERE — an omitted clause affects every row in the table.
Insert or update on conflict (upsert) 
INSERT INTO users (id, name) VALUES (1, 'Ada')
ON CONFLICT (id) DO UPDATE SET name = EXCLUDED.name;

MySQL equivalent: ON DUPLICATE KEY UPDATE name = VALUES(name).
Delete matching rows 
DELETE FROM users WHERE id = 42;
Schema
Create a table 
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  name TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);

SERIAL is Postgres-specific auto-increment; MySQL uses AUTO_INCREMENT, SQLite uses INTEGER PRIMARY KEY.

Add / drop a column 
ALTER TABLE users ADD COLUMN age INT;
ALTER TABLE users DROP COLUMN age;
Add an index 
CREATE INDEX idx_users_email ON users (email);
Users & Permissions
Create a user with a password 
CREATE USER app_user WITH PASSWORD 'change-me';

MySQL: CREATE USER 'app_user'@'%' IDENTIFIED BY 'change-me'; — the @'%' host part controls which hosts the user may connect from (@'localhost' restricts it to local connections only).

Change a user's password 
ALTER USER app_user WITH PASSWORD 'new-password';

MySQL: ALTER USER 'app_user'@'%' IDENTIFIED BY 'new-password';
Remove a user 
DROP USER app_user;

Fails if the user still owns objects or has granted privileges pending — reassign or revoke those first. Add IF EXISTS to avoid an error when the user is already gone.
Grant table privileges 
GRANT SELECT, INSERT, UPDATE ON users TO app_user;

Use GRANT ALL PRIVILEGES ON users TO app_user; for full access, or ON ALL TABLES IN SCHEMA public (Postgres) to apply to every existing table at once.

Revoke table privileges 
REVOKE INSERT, UPDATE ON users FROM app_user;
List a user's granted privileges 
SELECT * FROM information_schema.role_table_grants
WHERE grantee = 'app_user';

MySQL: SHOW GRANTS FOR 'app_user'@'%';
Window Functions & CTEs
Row number within a partition 
SELECT id, user_id,
  ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY created_at) AS rn
FROM orders;

Useful for picking "the latest row per group" by filtering rn = 1 in an outer query.
Running total 
SELECT id, amount,
  SUM(amount) OVER (ORDER BY id) AS running_total
FROM orders;
Common table expression (CTE) 
WITH big_orders AS (
  SELECT * FROM orders WHERE amount > 1000
)
SELECT * FROM big_orders WHERE user_id = 42;

Mainly for readability — most modern optimizers no longer treat a CTE as an opaque barrier the way older Postgres versions did.

Git Commands

Reverts, resets, rebases, branches, and worktrees worth remembering.

History & Commits
Reverting a PR 
git revert -m 1 <merge-commit-hash>
Resetting to an earlier commit 
git reset --hard <commit-hash> | <HEAD-{n}> | HEAD
Cherry-pick a commit hash 
git cherry-pick <commit-hash>
Cherry-pick a merged PR commit hash 
git cherry-pick -m 1 <commit-hash>
Rebase from HEAD 
git rebase -i <branch-name> | <HEAD-{n}>
Rebase from initial commit 
git rebase -i --root
Amend the last commit 
git commit --amend --no-edit

Drop --no-edit to change the commit message too. Never amend a commit that's already been pushed/shared unless you intend to force-push.
Compact one-line log graph 
git log --oneline --graph --decorate --all
Who changed this line (blame) 
git blame -L 10,20 path/to/file
Find the commit that introduced a bug 
git bisect start
git bisect bad
git bisect good <known-good-commit>

Git checks out a midpoint commit after each step — mark it git bisect good/bad until it narrows down the offending commit, then git bisect reset.

Inspecting Changes
Diff working directory vs last commit 
git diff

Add --staged (or --cached) to diff staged changes instead.
Diff two branches/commits 
git diff main..feature-branch
Show a file at a specific commit 
git show <commit-hash>:path/to/file
Search commit messages / diffs for a string 
git log --grep="fix login"
git log -S "functionName"

-S (the "pickaxe") finds commits that added/removed a given string in the diff, not just the commit message.
Undoing & Cleaning Up
Unstage a file (keep changes) 
git restore --staged path/to/file
Discard uncommitted changes to a file 
git restore path/to/file

Destructive — permanently discards local edits with no undo.
Stash / list / restore work in progress 
git stash push -m "wip"
git stash list
git stash pop

pop applies the most recent stash and removes it from the list; apply does the same but keeps it stashed.

Remove untracked files 
git clean -nd
git clean -fd

Always run -n (dry run) first to see what would be deleted before running -f for real.
Remotes & Syncing
Fetch and prune deleted remote branches 
git fetch --prune
Update local branch list from a fork/remote 
git remote add upstream <url>
git fetch upstream
Push a new local branch and track it 
git push -u origin HEAD
Force-push safely 
git push --force-with-lease

Fails instead of overwriting if someone else pushed to the branch since your last fetch — safer than a plain --force.
Branches
Renaming a branch 
git branch -m <old-branch-name> <new-branch-name>
Deleting a branch 
git branch -d <branch-to-delete>
List branches, including remotes 
git branch -a
Create and switch to a new branch 
git switch -c <new-branch-name>

Older equivalent: git checkout -b <new-branch-name>.
Worktrees
Adding a worktree 
git worktree add <branch-name>
Moving a worktree to a new location 
git worktree move <old-branch-location> <new-branch-location>
List / remove a worktree 
git worktree list
git worktree remove <path>
Combining All Commits
Squash all commits into one 
git switch yourBranch
git reset --soft master

Removes all commits but keeps the changes staged. Commit them together with git commit -m "commit message", then push with git push --force or git push --force-with-lease.

Regex Syntax

Core building blocks — mostly consistent across PCRE, JavaScript, and Python's re. Edge cases noted where flavors diverge.

Anchors & Boundaries
Start / end of string 
^foo
foo$

With a multiline flag, ^/$ match start/end of each line instead.
Word boundary 
\bcat\b

Matches "cat" but not "concatenate". \B is the negation (non-boundary).
Character Classes
Any character 
.

Doesn't match a newline unless a "dotall"/"s" flag is set.
Digit / non-digit 
\d
\D
Word character / non-word 
\w
\W

\w is [A-Za-z0-9_].
Whitespace / non-whitespace 
\s
\S
Custom set / negated set 
[aeiou]
[^aeiou]

A ^ as the first character inside [...] negates the set.
Character range 
[a-z0-9]
Quantifiers
Zero or more / one or more / optional 
a*
a+
a?
Exact / range count 
a{3}
a{2,4}
a{2,}
Lazy (non-greedy) match 
".*?"

Without the ?, .* is greedy and matches as much as possible — often too much across multiple quoted strings.
Groups & Alternation
Capture group 
(foo|bar)

Referenced later as $1/\1 depending on the tool.
Non-capturing group 
(?:foo|bar)

Groups for alternation/quantifiers without creating a numbered backreference.
Named capture group 
(?<year>\d{4})-(?<month>\d{2})

Referenced as $<year> (JS) or (?P=year) / m.group('year') (Python).

Backreference to an earlier group 
(\w+)\s\1

Matches a repeated word, like "the the". Use \1 in most flavors, $1 in replacement strings.

Lookaround
Lookahead / negative lookahead 
foo(?=bar)
foo(?!bar)

Matches "foo" only if (not) followed by "bar", without including "bar" in the match.
Lookbehind / negative lookbehind 
(?<=foo)bar
(?<!foo)bar

Not supported in all flavors/older engines — check target support before relying on it.

Common Flags
Case-insensitive 
/foo/i

Python: re.IGNORECASE. PCRE/grep: -i or inline (?i).

Global (all matches, not just first) 
/foo/g

JS-specific flag. Most other languages return all matches by default via a "findall"/"scan"-style function instead.
Multiline (^ and $ match per line) 
/^foo/m

Python: re.MULTILINE.
Dotall (. matches newlines too) 
/foo.bar/s

Python: re.DOTALL.

VSCode

Search patterns for the editor's find/replace.

Find mis-formatted i18n text 
i18n="([0-9a-zA-Z]+)"
Trailing whitespace 
[ \t]+$

Enable the regex toggle, leave replace empty to strip trailing spaces/tabs on every line.
Blank/empty lines 
^\s*$\n

Requires "match on multiple lines" enabled. Replace with nothing to collapse blank lines.
console.log statements 
console\.log\((.*)\);?\n?

Matches the whole line including the trailing newline, so replacing with nothing removes it cleanly.
TODO / FIXME comments 
\/\/\s*(TODO|FIXME).*$
Swap function call args (capture groups) 
myFunc\((\w+), (\w+)\)

Replace with myFunc($2, $1) to swap the two arguments.
Quoted string contents 
"([^"]*)"

Capture group $1 holds the text between the quotes — useful for swapping quote style or wrapping in a function.
Single-quote to double-quote strings 
'([^']*)'

Replace with "$1". Won't handle escaped quotes inside the string.
Unused single-line imports 
^import .* from ['"].*['"];\n

Search first to confirm the import is actually unused before replacing with nothing.
CSS hex color to rgb() parts 
#([0-9a-fA-F]{2})([0-9a-fA-F]{2})([0-9a-fA-F]{2})

Capture groups $1 $2 $3 hold the R, G, B hex pairs.
Lines containing a word (whole-word match) 
^.*\bdeprecated\b.*$

\b word boundaries stop it from also matching "undeprecated" or "deprecatedFlag".

No matches. Try a different search term.

Built as a quick-reference cheat sheet, not an exhaustive language spec — behavior can vary by version/runtime (e.g. PHP 7 vs 8, Java version, JS engine). When in doubt, check the language's own docs for edge cases like encoding, locale, and mutability.
